# سامانه هوشمند مدیریت پروژه‌ها — نسخه ۲ (V2)

نرم‌افزار تحت وب فارسی و راست‌چین برای مدیریت پروژه‌های عمرانی، پیمانکاری و سازمانی.  
**Standalone Frontend** — بدون سرور، قابل اجرا روی GitHub Pages.

> **توجه امنیتی:** احراز هویت فعلی سمت مرورگر است و برای دمو و کنترل دسترسی رابط کاربری طراحی شده.  
> این لایه را امنیت تجاری در نظر نگیرید. برای استفاده واقعی باید به ASP.NET Core + JWT/Cookie متصل شود.

## اجرای محلی

1. فایل‌ها را دانلود کنید.
2. `index.html` را با مرورگر باز کنید.
3. نیازی به نصب یا سرور نیست.

---

## انتشار روی GitHub Pages

1. مخزن جدید در GitHub بسازید.
2. محتویات پوشه پروژه را در ریشه مخزن قرار دهید.
3. Settings → Pages → Source: شاخه `main` و پوشه `/ (root)`.
4. آدرس نهایی: `https://USERNAME.github.io/REPO-NAME/`

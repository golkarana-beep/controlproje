# سامانه هوشمند مدیریت پروژه‌ها

نسخه اول (Standalone Frontend) — قابل اجرا بدون سرور و آماده انتشار روی GitHub Pages

## معرفی

سامانه مدیریت و تحلیل هوشمند پروژه‌ها یک نرم‌افزار تحت وب کاملاً فارسی و راست‌چین است که برای شرکت‌های پیمانکاری، مهندسی، ساختمانی، مشاوران و سازمان‌های اجرایی طراحی شده است.

### ویژگی‌های نسخه اول

- محیط کاملاً فارسی و RTL
- تقویم شمسی (جلالی)
- اعداد فارسی
- واحد پول ریال / تومان
- ذخیره‌سازی محلی (LocalStorage)
- داشبورد مدیریتی پیشرفته با نمودارها
- مدیریت پروژه‌ها، قراردادها، پیمانکاران، مشاوران
- مدیریت مالی و پیشرفت فیزیکی
- تحلیل هوشمند مبتنی بر قواعد
- گزارش‌گیری و خروجی
- تم روشن / تاریک
- واکنش‌گرا و بهینه‌شده برای موبایل (سایدبار کشویی، جداول اسکرول‌پذیر)
- انیمیشن‌ها و موشن‌گرافیک (ورود کارت‌ها، نور متحرک روی نمودارها)
- نمودارهای تعاملی: کلیک روی هر بخش لیست پروژه‌های مربوطه را نمایش می‌دهد
- بخش قیمت‌های روز بازار ایران (دلار، یورو، طلا، سکه، تتر و ...) با به‌روزرسانی زنده

### تکنولوژی‌ها

- HTML5 + CSS3 + JavaScript ES6+
- Chart.js برای نمودارها
- Lucide Icons
- jalaali-js برای تاریخ شمسی
- LocalStorage برای ذخیره‌سازی

## اجرای محلی

1. تمام فایل‌ها را دانلود کنید.
2. فایل `index.html` را با مرورگر باز کنید.
3. نیازی به نصب یا سرور محلی نیست.

## انتشار روی GitHub Pages

1. یک مخزن جدید در GitHub بسازید.
2. فایل‌های پروژه را در ریشه مخزن قرار دهید.
3. از بخش Settings → Pages، شاخه `main` و پوشه `/ (root)` را انتخاب کنید.
4. پس از چند دقیقه سامانه در آدرس `https://USERNAME.github.io/REPO-NAME` در دسترس خواهد بود.

## نکات مهم نسخه اول

- احراز هویت واقعی و دسترسی چندکاربره وجود ندارد (برای نسخه بعدی طراحی شده است).
- فایل‌های پیوست در نسخه اول با محدودیت LocalStorage/IndexedDB ذخیره می‌شوند.
- تمام محاسبات و تحلیل‌ها بر اساس داده‌های واقعی ثبت‌شده انجام می‌شوند.
- امکان پاک کردن داده‌های نمونه و ثبت اطلاعات واقعی وجود دارد.
